# Sudamérica AI — MVP

Repositorio monorepo del MVP (backend FastAPI, frontend Next.js y utilitarios). Este README resume los directorios principales y apunta a la documentación ordenada.

## Carpetas clave
- `backend/`: servicios FastAPI y workers.
- `frontend/`: frontend Next.js (tenant-facing).
- `sudamerica-admin/`: panel interno de administración.
- `modulos/`, `tools/`, `Scripts/`: utilidades y soporte de desarrollo/ops.
- `Docs/`: documentación organizada y categorizada (ver `Docs/README.md`). Incluye reportes y logs movidos desde `report/` y la raíz.
- `split-repos/`: repositorios generados al separar microservicios.
- `report/`, `Debug/`, `Include/`, `Lib/`, `share/`: artefactos de soporte y debugging (mantener según uso).

## Documentación
Lee `Docs/README.md` para el índice completo y convenciones de documentación.
